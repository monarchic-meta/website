# Original websites are the recreation targets

On 2026-11-01, the owner updated the [hero source list](../../design-inspiration/heroes.md#complete-owner-selected-list)
and instructed us to build from its original websites and recorded source works,
rather than their portfolio, gallery or award listings.

Use the **Original website / source post** column as the source of truth. Open
the entry URL first; chapter and category deep links are additional states.
For HERO-001 and HERO-002, inspect the original recorded works and the listed
direct media copies, including the newly supplied higher-resolution files.
Do not invent an interactive website for a recorded film.

The original site's current opening is the target when it differs from an older
gallery capture. Keep prior gallery-led studies and source contracts as
historical comparisons; their selected-revision policies do not override this
owner direction. Preserve existing editable work and attribution while revising
or adding the current-original experience.

Inspect the whole hero before building: its entry, meaningful timed states,
scroll progression, hover and pointer responses, reverse behavior, and handoff
to the following content. Observe each input separately. A first viewport,
gallery screenshot, source-code inference or one sampled loop is insufficient.
Record the URL, inspection date, viewport, input sequence and actual results.
Keep Desktop observations, Phone observations and responsive adaptations
distinct. Preserve credit for source-led recreations and adaptations.

Connected desktop-browser automation remains off after the reported wrong-chat
routing. Public original sites can be inspected in isolated local headless
Chromium with a fresh temporary profile, without desktop tabs or account
cookies. Framer authoring uses the independently verified project MCP
connection. Local source inspection, local implementation tests, MCP model
acknowledgments, frozen native images, and actual Framer Preview/reload are
different evidence levels.

The [handoff through the previous authoring round](handoff.md) records that
baseline. Its page inventory does not establish fidelity to the newly clarified
original-site targets. The new original-site audit must identify which existing
studies already match and which require source-specific changes.
