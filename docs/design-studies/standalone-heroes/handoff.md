## Responsive display correction

Actual Preview exposed a retained-buffer issue when a live Desktop component
became Phone: a 1200×833 display could keep its larger total area while receiving
a 443×1024 Phone source. Its vertical output then fell below demand. The shared
copy condition now retains a buffer only when both axes are sufficient. The
[explicit source lineage](../code-components/responsive-display-fix.json) records
the exact before/after hashes for all eighteen embedded coordinator copies.
Of the eighteen code files in the sealed earlier project, sixteen change only
this three-byte condition. `LogoDropStudy.tsx` and
`HomepageNavigationInteractions.tsx` remain byte exact. The two new renderers
also use the corrected coordinator. The new source-page component additionally
owns Origin's 30% corner radius after Framer's incoming style, so its small tile
does not become square through an intermediate wrapper. No drawing geometry,
source data, public controls or native presets change. Historical manifests
retain their original hashes.

The current regression changes the same entry between Desktop and Phone while
live, paused and restoring a larger canonical cached frame. Actual Chrome
compares all three displayed results with fresh renders at the retained phase;
all three have sufficient axes and zero changed pixel channels. The complete
mixed suite also retains its prior budget, handoff, rollback and cleanup checks.
Every registered copy must be updated and the editor/Preview reloaded, because
an already-instantiated per-window pool retains its previous closure. The final
whole-project source proof must allow only these enumerated corrections rather
than claim the earlier source hashes stayed unchanged.

## Credit and intentional limits

Source-led code remains a recreation, even though its layers and renderer were
newly authored. Type Face and the raster portrait use the explicitly credited
Lee Perry-Smith head scan as a geometry stand-in under CC BY 3.0. It is not
verified as the source's own mesh. Mac Moss uses source contours sampled at
12 fps; its source algorithm was not recovered. Cantor8, the selected dark
Vercel revision, MECHA hidden-line treatment and Origin light movement retain
their documented motion or material approximations. Imported film frames and
photographs remain comparison media or still assets, not recreated animation.
Read each recipe's limits before transferring the study to production.

The originals use repository vocabulary, existing ExplicitMem report text and
question counts, and the SystemField architecture model. Their edited crops
are visual metaphors, not new papers, combined evaluations or live telemetry.
OH-012/016/018 use the owned Monarchic mark. No foreign identity assets are
reclassified as original work.
