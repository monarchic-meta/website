# Original hero studies

The owner requested original Monarchic openings after the
[eighteen selected hero references](../../design-inspiration/heroes.md) had been
recreated and verified. This round explores six independent directions first,
then three original combinations of **immersive information field**, **evolving
geometric identity** and **editorial research montage**.

Nine candidates are saved and verified in the existing Framer project. All
eighteen Desktop/Phone Preview cases animate, pause and resume; all nine editor
Canvas opt-ins work and are restored to off. The [manifest](manifest.json) binds
the exact source, recipes, registered controls, page/layer identities and proof.

## Creative scope

OH-001–002 explore information fields, OH-003–004 geometric identity and
OH-005–006 research montage. OH-007–009 combine those three ideas. All are
independently composed work for **Original compositions**. The source references
inform mechanisms, material, scale and composition; their recognizable layouts,
marks, imagery and source algorithms are not imported into these originals.

OH-003 and OH-008 reuse the existing owned canonical Monarchic mark. Their
staging, material and motion are new; the logo geometry itself is not newly
authored. Its pinned asset and hash remain in the manifest.

The opening should communicate Monarchic's research and development identity
with quiet confidence and an immediately distinctive graphic idea. Primary
headlines, copy, links and framing remain native editable Framer layers. Live
graphics use a self-contained code component. Experimental material is a visual
metaphor, not a claim of measured results or a live operational dashboard.

These are opening studies, not complete homepage implementations. Existing
homepage concepts, navigation, source recreations, live studies and original
graphic collections remain preserved. The
[homepage brief](../../homepage-creative-brief.md) continues to govern the later
identity → problems → flagship-products journey and ordinary scrolling.

## Runtime and verification

The new graphics use Canvas 2D, procedural geometry and tonal dithering. They do
not require a runtime image/model download or an additional WebGL renderer.
Canvas motion defaults off; Preview motion defaults on. Static exports and
thumbnails remain frozen. Motion, rendering resolution and caches use the
existing shared study coordinator and its resource limits.

The grouped Nix check passed on the exact registered source: 15 focused groups,
216 mixed placements across Canvas and Preview, and 18 actual local browser
pixel cases. The source has no registration diagnostics. The local composites
use fallback font metrics; actual Framer editor and Preview captures are
separate evidence. All four Design boards were inspected after fresh editor
loads, including native copy, credits, OH-004's diagonal plane/type and Phone
layout. All 18 actual Preview live pairs show visible artwork movement; all 18
paused pairs have identical interior RGB pixels. Canvas opt-in was separately
tested on each of the nine Design instances, with only one editor study moving
at a time; turning it off restores the still frame at phase 3.

The preceding organized baseline contains 34 pages, 160 code placements and 17
source files. This additive round creates eight pages, 27 instances and one
source. The saved project now contains **42 pages, 187 code placements and 18
sources**. The independent preservation audit passed 31 checks: all 34 preceding
complete page trees, 160 full instance records, 17 sources, 2,365 old link
objects, 45 global styles, two native definitions and ten override bindings are
exact. The eight new complete trees also match their initially validated state
after UI motion restoration. All 27 new instances retain their exact presets
with Canvas motion off; the old 60 opt-ins remain unchanged.

The new native graph contains 793 model records. Saved serialization adds only
135 exact default link-option dictionaries and uses 567 narrowly declared
position omissions; no old-tree normalization is permitted by the audit. All
native geometry, rotation, colors, content and sibling order match the reviewed
recipes. The writer's 32 preservation checks and the independent 31 checks are
separate from local rendering and actual browser proof.

Evidence is retained under `original-heroes-2026-10-31` in the session's
visualization directory. The manifest records relative evidence paths and
SHA-256 hashes for the Nix receipts, saved model, independent audit, browser
verification and actual Preview pixel audit. No hardware frame-rate claim is
inferred from local software-rendering timings.
