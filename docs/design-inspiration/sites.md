# Site reference index

Verified **2026-10-22**. This separates a site's current state from the older
post that led to it. Use with the [catalog hub](../design-inspiration.md) and
[web references](web-ui.md). A verified destination does not mean the complete
site, its mobile layout, or its interactions were audited.

## SITE-001 — CROX

- Destination: [live template demo](https://crox.framer.website/), directly linked from the [official Framer listing](https://www.framer.com/marketplace/templates/crox/).
- Attribution: Konrad Makowski; listing and demo footer identify the creator. Source: WEB-002.
- Inspected: Desktop homepage hero and the next section visually; page text inspected. Heavy black navigation-cell borders, pale gray vertical grid, huge black type, orange actions, a wireframe object, and aligned system-status rows.
- Useful for: Strong structural starting point for a technical company site. Treat the demo's business claims, addresses, and metrics as template content.
- Unchecked: Mobile, service/process subpages, navigation flows, keyboard behavior, and animation/performance.

## SITE-002 — a New Scaffolding

- Destination: [official site](https://www.anewscaffolding.com/).
- Attribution: Fashion archival service; homepage credits development to Targa studio. Source: WEB-013's first Framer roundup.
- Inspected: Desktop landing page visually and page identity through HTML. A thin black table-like grid on white divides a large expressive serif identity, bold sans introductory text, a utility strip, service cells, and compact footer facts.
- Useful for: Information as architecture, strong cell boundaries, a clear contrast between identity type and functional type.
- Unchecked: Service-cell interactions, moving imagery from the roundup, mobile layout, keyboard behavior, and performance.

## Verification notes

The first Framer roundup's four destinations were corroborated through Framer's
published roundup text and the destinations' own pages. The a New Scaffolding and
TRYBREATHING URLs were resolved from the outgoing links in Framer's official
LinkedIn roundup, rather than inferred from their names. The [company feed](https://hk.linkedin.com/company/framer)
is mutable, so retain WEB-013's public X permalink as the visual source.

Concept names such as Meridian, Voxa, Mapping-OS, Lumen Studio, and NORD remain
post-only references until an associated live URL is verified. Avoid substituting
a similarly named company's site. Append new SITE IDs without renumbering old
entries, and date changes in inspection scope.
