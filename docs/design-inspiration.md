# Design inspiration catalog

Curated references for Monarchic's website, graphic elements and Framer experiments.
The owner's direction includes **expressive Swiss, neo-brutalism, cyberpunk,
digital design, neo-Y2K and actual dithering**. Explore the full mix, including
non-type geometry, material, light, texture and composition.

Swiss here includes typesetting as image: colorful bold words, sideways or cropped
text, asymmetry and unexpected placement. Clean fonts or functional controls alone
do not define the brief. The [visual-language brief](design-inspiration/visual-language.md)
records the independent directions and concrete motifs to make more of.

## How to use and maintain it

Choose a few reference IDs and state the specific trait being adapted. For example:
"GRA-001-03 for staggered type, GRA-012 for chrome, WEB-006 for tonal dither."
Name the source key when an entry groups several posts. The application can be
a hero, graphic panel, transition, identity element or control; it need not be
decided before exploring the visual.
Record the chosen Framer project/node and the resulting decisions through the
[manual handoff workflow](framer-prototyping.md). The prototype defines a proposed
design; repository code and shared catalogs define the implemented behavior and
product facts.

For graphic-element studies, inspect the reference and rebuild its motif from
native Framer shapes, text, and named groups so the parts remain editable.
Retain source keys and simplification notes; keep post previews in the comparison
library and source-led recreations in Source inspiration.

Give each new reference the next unused ID in its collection (`WEB`, `GRA`,
`CC` or `SITE`). Preserve IDs when titles change. ART-001–006 are retired and must not
be reassigned. Record the creator or posting account,
public permalink, observed visual traits, intended application, evidence scope,
and review date. Related posts can share an entry when they demonstrate one
coherent system. Keep site destinations in the site index so their verification
status can be updated independently of an older post.

Use original composition and assets when implementing a direction. Attribution
and a bookmark are not an asset license. Keep factual labels and metrics tied to
Monarchic's actual products and research. Test readable type, contrast, keyboard
use, responsive layouts, and reduced motion when a design becomes implementation.

Post observations come from visible image previews and sampled video frames,
with exceptions noted per entry. WEB-017’s four gallery images were reviewed at
overview resolution; other galleries were not exhaustively opened, and complete
clips were not audited. A desktop screenshot or a mobile
mockup inside a post does not establish responsive behavior, accessibility,
performance, or functioning interactions. Site identities and current layouts
can differ from the bookmarked revision.

Only public source links and original notes are retained here. The catalog does
not contain account credentials, a private bookmark export, or copied source
artwork. It is maintained in the repository; there is no runtime X feed or
automatic Framer synchronization.
